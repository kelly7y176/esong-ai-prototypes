1. Executive Summary & AI System Architecture

This document presents the engineering and UX architecture for the E-Song AI Short Video Creation Platform. Designed for diverse creator personas, the solution explores three distinct interaction paradigms—ranging from touch-first mobile editing to interactive gamified wizard creation and multi-track desktop studio workflows.

// Core End-to-End Generative Pipeline:

1. Prompt Synthesizer & Presets ➔ 2. Storyboard Keyframe Generation ➔ 3. Multi-Lens & Style Inspector Tuning ➔ 4. Character Avatar Binding ➔ 5. Multi-Track Video Composition Preview

2. Detailed Breakdown of 3 UX Paradigms

Prototype 01: Minimalist Mobile (Mobile-First UX)

320px - 430px Target

Target Persona: Vlogging creators, social media video editors (Reels / TikTok).

  • Interaction Model: Single-column touch card layout with sticky 44px+ touch-target bottom navigation bar.
  • AI Workflow: One-tap prompt chip presets for low-friction creation on mobile viewports.
  • Strategic Trade-off: Prioritized viewport real estate and touch simplicity over deep multi-track video timeline controls.

Prototype 02: Cyberpunk Interactive Wizard (Guided Gamification)

Adaptive Multi-Device

Target Persona: Digital artists, indie game developers, sci-fi creators.

  • Interaction Model: Sequential 4-step wizard (Synthesize ➔ Tune ➔ Avatar ➔ Render Matrix) to eliminate cognitive overload.
  • AI Workflow: Interactive prompt randomizer card paired with dark neon cyberpunk aesthetics.
  • Strategic Trade-off: Strict step-by-step wizard reduces non-linear editing speed but guarantees high task completion rate for beginners.

Prototype 03: Professional Studio Workbench (Desktop NLE)

1024px - 1440px+ Target

Target Persona: Professional video editors, commercial production teams.

  • Interaction Model: Industry-standard 3-column NLE studio grid with concurrent multi-track timeline inspector.
  • AI Workflow: Granular real-time camera lens, style matrix, and character binding property controls.
  • Strategic Trade-off: High information density required adaptive panel tabs for viewports under 1024px.
