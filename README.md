## 🛠️ Tech Stack & Architecture

* **Frontend**: HTML5, Tailwind CSS (via CDN), Vue 3 (Options API)
* **AI Integration**: Shared `ai-service.js` with client-side state management and reliable serverless fallbacks
* **Accessibility**: Semantic HTML5 landmarks (`<header>`, `<main>`, `<aside>`, `<nav>`) and WCAG 4.5:1 color contrast
